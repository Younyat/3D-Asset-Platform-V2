1. La idea en una página

Cada objeto de la escena es un módulo independiente que no conoce a los demás. Todos exportan lo mismo — un objeto MODEL con sus metadatos y una función create(THREE, opts)— y toda instancia expone la misma superficie. Esa uniformidad es lo que permite quitar un objeto, sustituirlo por otro o cargar solo dos de los seis, sin tocar el código que los maneja.

const inst = create(THREE, opts);

inst.root                  // THREE.Group para añadir a la escena
inst.model                 // metadatos: joints, clips, huella, señales
inst.setJoint(id, valor)   // escribe UN eje (grados o metros), recortado a límites
inst.getJoint(id)          // lee el valor actual
inst.setPose({ ... })      // pose completa de una vez
inst.playClip(name, {loop})// reproduce una animación incluida
inst.stopClip()            // libera los ejes para control manual
inst.update(dt)            // avance por frame — SIEMPRE, o nada se mueve
inst.signal(name, payload) // entrada de señal externa
inst.diagnose()            // qué ejes y clips existen realmente
inst.dispose()             // libera geometrías y materiales
El error número uno. Sin inst.update(dt) dentro del bucle de render nada se mueve, aunque el clip esté «reproduciéndose». Es una línea por objeto, o un bucle sobre el registro. Todo lo demás son detalles.

import * as THREE from 'three';

gantry.root.rotation.y = -0.785;

3.1 Control por código en vez de clips

gantry.stopClip();                       // libera los ejes del clip

gantry.setJoint('G1', 45);               // grados, recortado a ±180
gantry.setJoint('G3', -0.45);            // metros, recortado a [−0,62 … 0]
gantry.setJoint('G5', -8);               // garra cerrada

gantry.setPose({ G1: 45, G2: 0.5, G3: -0.45, G4: 90, G5: -8 });

gantry.speedScale = 0.5;                 // cámara lenta, afecta a clips y a tick()

3.2 Servo con límite de velocidad

Para trayectorias propias en vez de clips, la velocidad máxima de cada eje está en MODEL.joints[].speed. El conjunto se mueve al ritmo del eje más lento, de modo que todos llegan a la vez y la trayectoria es una sola curva limpia:

function moveAll(inst, target, dt) {
  const js = inst.model.joints.filter(j => j.id in target);
  let T = 0;
  for (const j of js) T = Math.max(T, Math.abs(target[j.id] - inst.getJoint(j.id)) / j.speed);
  const f = T > 0 ? Math.min(1, dt / T) : 1;
  for (const j of js) {
    const cur = inst.getJoint(j.id);
    inst.setJoint(j.id, cur + (target[j.id] - cur) * f);
  }
  return T <= dt;                        // true cuando ha llegado
}

4. El registro: quitar, poner y sustituir

La flexibilidad no está en los modelos: está en cómo la plataforma los guarda. Un registro por ranura —un Map de slot → { instancia, configuración }— es todo lo que hace falta. Quitar es dispose más borrar la entrada; sustituir es quitar y montar otro módulo en la misma ranura, con la misma colocación.

const registry = new Map();

async function mount(slot, cfg) {
  const mod = await import(cfg.module);
  const inst = (cfg.create ? mod[cfg.create] : mod.create)(THREE, cfg.opts || {});
  inst.root.position.set(...cfg.pos);
  inst.root.rotation.y = cfg.rotY || 0;
  scene.add(inst.root);
  registry.set(slot, { inst, cfg });
  return inst;
}

function unmount(slot) {
  const e = registry.get(slot);
  if (!e) return false;
  e.inst.dispose();                       // libera geometrías y materiales
  registry.delete(slot);
  return true;
}

async function replace(slot, cfg) {
  const prev = registry.get(slot)?.cfg || {};
  unmount(slot);
  return mount(slot, { ...prev, ...cfg }); // conserva colocación, cambia modelo
}

Con eso la escena tolera cualquier combinación: cargar solo la cinta, sustituir un tramo de 3,25 m por uno de 4,30 m, cambiar la pila de 2×3×2 por 3×3×2, o quitar el operario. El ciclo maestro comprueba la presencia con get(slot)?.signal(...), así que una ranura vacía simplemente no recibe órdenes.

El archivo 06-escena-completa/scene.html es esa idea funcionando: el panel lateral quita, repone y sustituye objetos en vivo, sin recargar.

6. Ciclo maestro de 12 segundos

Una caja en juego por ciclo. La coordinación no vive dentro de los modelos: vive en un árbitro externo que emite señales. Ningún objeto lee el estado interno de otro.

const clock = new THREE.Clock();

renderer.setAnimationLoop(() => {
  const dt = clock.getDelta() * speedScale;
  for (const { inst } of registry.values()) inst.update(dt);   // UN SOLO RELOJ

  const prev = t; t += dt;
  for (const e of CYCLE) {                       // flanco INCLUSIVO en t = 0:
    const id = `${e.t}:${e.signal}`;             // las señales del instante 0
    if (fired.has(id)) continue;                 // arrancan el ciclo y con
    if (e.t >= prev && e.t < t) {                // `e.t > prev` no se
      fired.add(id); handle(e);                  // dispararían nunca.
    }
  }
  if (t >= 12) { t = 0; fired.clear(); }         // reinicio exacto, sin residuo

  renderer.render(scene, camera);
});

7. Traspaso de piezas

El traspaso es el único punto donde dos objetos se tocan, y se resuelve siempre igual: reemparentar conservando la transformación mundial.

Incorrecto
// la caja salta de sitio
cinta.root.add(caja.root);
caja.root.position.copy(pos);
Correcto
// conserva la posición visible
cinta.root.attach(caja.root);
cinta.addCargo(caja.root);

Mientras la caja es hija de un nodo articulado, se mueve con él sin ninguna línea adicional. Para que la cinta la haga avanzar hace falta además registrarla con addCargo(): es lo que distingue una caja transportada de una caja apoyada.

9. Exportar a otras plataformas

Cada visor de viewers/ lleva un exportador: Download GLB produce el objeto con su jerarquía de nodos nombrada, materiales PBR, clips de animación y los metadatos del modelo en userData (campo extras del glTF). El OBJ es solo estático: no soporta jerarquía ni animación.

DestinoNotas
three.jsUso directo de los módulos, sin exportar. Es el camino recomendado: conserva el contrato y los canales no geométricos (luces, pantalla, textura de banda), que el GLB no puede llevar.
UnityImportar el GLB con glTFast. Escala 1 (metros). Los ejes channel no viajan: reimplementarlos con la tabla de la especificación.
UnrealImportar con Interchange, escala 100 (centímetros). Mano izquierda: verificar signos con Demo_Ejes.
BlenderImportación directa del GLB. Reexportar siempre con +Y up y sin aplicar transformaciones a los nodos articulados.
Variante escalada. Todos los modelos aceptan escala uniforme en el nodo raíz sin romper nada: inst.root.scale.setScalar(100) da centímetros. Los valores de setJoint siguen siendo grados y metros — el contrato es independiente de la escala de presentación.

10. Añadir un objeto nuevo

Un modelo nuevo encaja en la escena si cumple el contrato. El esqueleto mínimo:

import { ModelBase, makeHelpers } from '../_shared/model-api.js';

export const MODEL = {
  id: 'mi-objeto', version: '1.0', label: 'Mi objeto',
  rootName: 'MiObjeto', units: 'meters', up: 'Y',
  footprint: { width: 1, depth: 1, height: 1 },
  joints: [
    { id: 'A1', name: 'A1_yaw', type: 'revolute', axis: 'Y',
      label: 'A1 · Giro', limits: [-90, 90], speed: 60, home: 0, unit: '°',
      moves: 'Qué hace y qué arrastra.' },
  ],
  clips: [{ name: 'Ciclo', duration: 4, loop: true, does: 'Qué hace.' }],
  signals: { RUN: (m) => m.playClip('Ciclo') },
  interop: { provides: [], consumes: ['RUN'], pairsWith: [] },
};

export function create(THREE, opts = {}) { return new MiObjeto(THREE, opts); }

class MiObjeto extends ModelBase {
  constructor(THREE, opts) {
    super(THREE, MODEL, opts);
    const { box } = makeHelpers(THREE);
    const A1 = new THREE.Group(); A1.name = 'A1_yaw';
    this.root.add(A1); this.bind('A1', A1);
    A1.add(box(0.4, 0.4, 0.4, new THREE.MeshStandardMaterial(), 'cuerpo'));
    this.buildClip('Ciclo', [{ t: 0, A1: 0 }, { t: 2, A1: 90 }, { t: 4, A1: 0 }]);
    this.goHome();
  }
  tick(dt) { /* movimiento paramétrico, si lo hay */ }
}

Con eso el visor genérico lo muestra con sus sliders y sus clips sin escribir interfaz, el registro lo monta en cualquier ranura, y el ciclo maestro puede enviarle señales. No hace falta nada más.
