1. Qué es este activo

Cinta de banda plana sobre bastidor de perfil de aluminio: dos tambores (motriz y de retorno), banda de caucho, perfiles guía laterales, tres pares de patas con pie regulable y un tope neumático que retiene la pieza en la estación de recogida. Incluye cuatro cajas de relleno para visualizar el transporte, agrupadas aparte para poder ocultarlas.

El movimiento no es una animación por keyframes como en los brazos: es movimiento continuo paramétrico. Se define por una velocidad en m/s, y de ella se derivan el desplazamiento de la banda, el giro de los tambores y el avance de las piezas. Por eso el archivo no lleva clips: lleva un contrato de movimiento que la plataforma implementa en tres líneas.

Donde d = velocidad · dt es la distancia recorrida por la banda en el frame. El paso de nervadura de la banda es 0,12 m, de ahí el divisor del desplazamiento de textura. Todos estos valores viajan dentro del GLB, en userData, con el esquema conveyor-rig/1.0.

5. Implementación del movimiento

const conveyor = gltf.scene;                       // ConveyorBelt2400
const belt = conveyor.getObjectByName('belt_top').material.map;
const R1 = conveyor.getObjectByName('R1_drive_roller');
const R2 = conveyor.getObjectByName('R2_idler_roller');
const parts = [1,2,3,4].map(i => conveyor.getObjectByName(`P${i}_part`));

let speed = 0.25;            // m/s
let stopperUp = false;
const PICK_X = 0.78;         // posición X de PICK_STATION

function update(dt) {
  const d = speed * dt;
  belt.offset.x -= d / 0.12;                       // banda
  R1.rotation.z -= d / 0.055;                      // tambores: eje de giro Z
  R2.rotation.z -= d / 0.055;

  for (const p of parts) {                         // piezas
    let x = p.position.x + d;
    if (stopperUp && p.position.x <= PICK_X && x > PICK_X) x = PICK_X;
    if (x > 1.4) x = -1.4;                         // reentrada cíclica
    p.position.x = x;
  }
}

function setStopper(up) {                          // tope neumático
  conveyor.getObjectByName('S1_stopper').position.y = up ? 0.80 : 0.71;
  stopperUp = up;
}
Piezas propias. PARTS_optional es geometría de relleno para ver el transporte. En producción conviene ocultarla (visible = false) y hacer avanzar las piezas reales de la escena con la misma fórmula x += velocidad · dt.

7. Estaciones

MarcoPosición local (x · y · z)Para qué sirve

PICK_STATION0,78 · 0,808 · 0Recogida. Coincide con el tope S1: la pieza se detiene exactamente aquí y el brazo industrial la toma.

Son nodos vacíos: no tienen geometría y sirven como marcos de referencia. Para colocar los robots, basta leer la posición mundial de estos nodos y situar sus bases a la distancia de alcance adecuada.

8. Papel en el escenario conjunto

La cinta es el eje del flujo: entra material por INFEED_STATION y sale por PICK_STATION. Su tope es el mecanismo de sincronización con los brazos: mientras está subido, la pieza está inmóvil y el agarre es determinista. El protocolo de señales entre los tres activos está en Documentación del escenario conjunto.

9. Verificación tras importar

  • Existen los nodos BELT_surface, R1_drive_roller, R2_idler_roller, S1_stopper, PICK_STATION, INFEED_STATION.
  • La banda tiene un material con textura (belt_surface) y esa textura está en modo repetición: sin ello el desplazamiento no se ve.
  • Al aplicar la fórmula de la sección 5, la banda y los tambores giran en el mismo sentido y a la misma velocidad lineal.
  • Con el tope subido, las piezas se detienen en x = 0,78 y no lo atraviesan.
  • La superficie de la banda queda a 0,80 m y las patas apoyan en y = 0.
  • Cinco materiales PBR con nombre: frame_alu, frame_alu_dark, belt_surface, bolt_steel, part_carton.
